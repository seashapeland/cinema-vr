# 大厅媒体自定义

常规媒体路径在 `config.json` 中配置，取票内容在 `ticketing.json` 中配置；修改后刷新页面即可。

- `cinemaName`：全局影院品牌名，会同步用于大厅招牌、影厅等待画面、遥控器和电影票。`labels` 与 `uiText` 中可以写 `{cinemaName}` 自动引用它。
- `images.gameScreen`：大厅游戏设备的 `16:9` 横屏图片。
- `images.auditoriumRear`：影厅最后方的大幅壁画，推荐约 `16:5`。留空字符串时使用内置星空壁画；其他比例会完整显示并自动留边，不会裁切。
- `labels`：大厅及室外建筑招牌。每项支持 `title`、`subtitle`，还可以用可选的 `accent` 设置强调色。
- `marquee`：室外竖向首映灯箱的品牌、场次、影厅、时间和位置文字。
- `uiText`：影厅等待画面、传输机、遥控器按钮与状态文字，以及内置后墙壁画的标题和副标题。
- `posters`：影厅入口声闸走廊两侧海报，推荐竖版 `2:3`。
- `trailers`：前四项对应柜台上方屏幕，第五项对应左侧大型预告电视。支持 MP4/WebM；留空时使用内置动态画面。
- `standees`：大厅中央立体海报，使用 `{ "front": "正面路径", "back": "反面路径" }` 分别配置两面；旧版数组格式仍然兼容。
- `ticketing.json`：自助取票机影片配置。`config.json` 的全局 `cinemaName` 优先作为电影票影院名，`currency` 控制币种；每部影片可定义 `id`、`name`、`poster`、`showtime`、`hall`、`seat` 和 `price`。海报路径既可使用本文件夹下的资源，也可换成项目 `public` 目录中的其他绝对路由。屏幕与电影票会实时生成，无需取票机贴图。
- `music`：大厅背景音乐，例如 `/lobby-media/music/lounge.mp3`；留空则不播放。
- `musicVolume`：大厅音乐音量，建议 `0.15`–`0.4`，最大限制为 `0.65`。

大厅音乐会在走廊和影厅入口处逐渐被墙体低通并衰减，深入影厅后停止，因此不会与电影声音明显叠加。浏览器需要用户首次单击画面后才允许播放音频。

每次网页会话只保留当前打印的单张电影票；进出影厅或刷新网页后自动清除。出票后电影票会拿在第一人称右手中：按 `H` 隐藏或重新拿出，按 `R` 放大或放回手持位置，放大时也可按 `Esc` 收回。

大厅会同时解码五段预告片。请仅在 `trailers/optimized/` 中使用面向小屏幕压缩过的版本；把原始母版放在 `trailers/` 顶层后，可在项目根目录运行 `npm run media:compress` 批量生成。完整参数、画质分级和 FFmpeg 安装说明见项目根目录 [`README.md`](../../README.md#为什么必须压缩预告片)。
